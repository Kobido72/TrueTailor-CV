מפתח API של Google Gemini

המפתח נשמר בדפדפן שלך בלבד ולא נשלח לשום מקום מלבד Google. אם תסירו את הסימון למעלה, הוא יימחק עם סגירת הלשונית.

איך משיגים מפתח API בחינם

אין דרך ליצור מפתח אוטומטית מתוך האפליקציה, גוגל לא מאפשרת זאת. הדרך היחידה היא דרך הדף הרשמי:

  1. לחץ על הכפתור "🔑 קבל מפתח API בחינם", נפתח טאב חדש ב־Google AI Studio.
  2. לחץ על Create API key.
  3. בחר פרויקט Google Cloud קיים או צור חדש בלחיצה אחת.
  4. העתק את המפתח שנוצר.
  5. חזור לאפליקציה, הדבק בתיבה למעלה, לחץ שמור ואז בדוק חיבור.

הדף שלמטה הוא בגודל A4 אמיתי, והקו המקווקו מסמן איפה מתחיל עמוד חדש בקובץ.

✎ הדף למטה ניתן לעריכה. לחץ על כל שורה וכתוב ישירות עליה, בדיוק כמו במסמך. כשתסיים לחץ "החל שינויים" בתחתית, אחרת העריכות לא ייכנסו לקובץ.
יש עריכות שלא הוחלו. לחץ "החל שינויים" כדי לקבע אותן.

להגשה למערכות ATS עדיף קובץ Word. כל הטמפלטים הם עמודה אחת של פסקאות רגילות, בלי טבלאות ובלי תיבות טקסט, כדי שהעיצוב לא יבלבל את המערכת. כשמעלים קורות חיים כקובץ Word נוסף טמפלט נוסף שמשחזר את הגופן, הגדלים והצבע של הקובץ שלך.
