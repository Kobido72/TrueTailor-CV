מפתח API של Google Gemini

המפתח נשמר מקומית בדפדפן שלך (localStorage) ולא נשלח לשום מקום מלבד Google.

איך משיגים מפתח API בחינם

אין דרך ליצור מפתח אוטומטית מתוך האפליקציה, גוגל לא מאפשרת זאת. הדרך היחידה היא דרך הדף הרשמי:

  1. לחץ על הכפתור "🔑 קבל מפתח API בחינם", נפתח טאב חדש ב־Google AI Studio.
  2. לחץ על Create API key.
  3. בחר פרויקט Google Cloud קיים או צור חדש בלחיצה אחת.
  4. העתק את המפתח שנוצר.
  5. חזור לאפליקציה, הדבק בתיבה למעלה, לחץ שמור ואז בדוק חיבור.
